# Poddar Jewellers

Bringing a jewellery shop in Palojori, Deoghar, Jharkhand online.

A premium catalog where customers browse from home and see a realistic,
all-inclusive estimated price — even though gold and silver rates change daily.
The shop updates the rate once a day; the entire catalog re-prices itself.

**Status:** Phase 1 design complete, implementation not started. See
[`docs/STATUS.md`](docs/STATUS.md).
